# 출판 작업실 대시보드

맥북과 맥미니의 출판 관련 프로젝트를 2026-09-08에 실제 파일, Git 상태, SSH 연결을 기준으로 정리한 정적 대시보드입니다.

## 열기

`index.html`을 브라우저에서 직접 열거나 아래처럼 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다.

## 데이터 범위

- Mac mini: `~/projects/novel01`, `fairy_tale`, `fairy_tale_office`, `ai_crew`
- MacBook: `publish_test`, `Book_notes`, `family-book-log-001`, `how_to_steal_a_dog`, `the_martian`
- 진행률은 파일과 진행상황 문서를 바탕으로 한 작업 단계 추정치입니다.
- 대시보드는 현재 스냅샷이며 원본 프로젝트 파일을 수정하지 않습니다.
